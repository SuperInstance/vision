# vision — the refined dream, documented

This repo is the council chamber and the compass for the SuperInstance
agent ecosystem (zero-poc and its satellites). It exists so that the
*ideas* — not just the code — are versioned, attributed, and argued in
writing.

## Contents

- `council/brief.md` — the shared context given to both competing models
  (2026-10-16 council: Claude Code opus vs MiniMax mcode).
- `council/submission-claude.md` — claude's submission (verbatim).
- `council/submission-mcode.md` — mcode's submission (verbatim).
- `council/synthesis.md` — the moderator's (ZCode) convergence/divergence
  analysis and the adjudicated outcome.
- `council/plan-round2.md` — both models' concrete plan critiques on the
  synthesized roadmap (round 2).
- `PLAN.md` — THE PLAN: the roadmap of record after the council.
- `research/` — subagent scouting reports (edge mesh, world models).

## Method

Two frontier models receive the same brief and compete for the sharpest
insight, abstraction, refined dream, and roadmap surgery. A third agent
(ZCode) synthesizes — crediting the winner of each idea — and the result
becomes the roadmap of record. Everything measured lives in the PoC
repos (gate-replay, minigate, cycle-judge); everything *meant* lives
here.

## Standing context

Solo human builder (Casey) + AI agents doing the work. zero is a live
git-native agent on GitHub Actions with a vault-gated LLM brain. The
System-1 layer (fast cheap confidence-scored judgments gating and
judging expensive reasoning) is built and measured. The strategic reframe:
the gate buys cadence, not just savings — a batch agent becomes a
responsive one at the same cost envelope.
